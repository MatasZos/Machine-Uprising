# Machine Uprising

2D lane-based tower defence game.

## Stack
- TypeScript
- Phaser
- npm
- Git / GitHub

## Scrum 1
- Five lanes
- Placement grid
- Rifle Soldier
- Drone enemy
- Projectiles
- Health/damage
- Enemy death

## Structure
`src/scenes` — Phaser scenes  
`src/defenders` — defender classes  
`src/enemies` — enemy classes  
`src/objects` — projectiles/game objects  
`src/managers` — waves and energy  
`public/assets` — game art/audio
